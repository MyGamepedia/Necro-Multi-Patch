These has nothing to do with the plugin itself, these are just 2 Ghidra .py scripts MyGamepedia used a lot locally for this project. "FindFullSign.py" is for quick full signature on Windows, open in C decompiler any function you want and run the script to get signature in the console. "sourcecoopScriptGPT.py" is for improved C decompiled code by loading field names from datamaps and netprops, you'll need XML versions, original script version by SourceCoop developers.
